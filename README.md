# SREE DEV HOSPITALITY Website

Five-page responsive static HTML/CSS/JS website.

## Deployment
1. Upload the contents of this folder (not the enclosing folder) to `public_html` on cPanel, or deploy the folder as a static site on Render / GitHub Pages.
2. **IMPORTANT:** Replace `https://YOUR-DOMAIN.example/` with your actual production base URL in all five HTML files, `sitemap.xml`, and `robots.txt`. These placeholders are intentionally not a live domain.
3. Check links, SSL, mobile layout, Google Maps URL, and WhatsApp before launch.
4. Submit the production sitemap to Google Search Console.

## Notes
- The original uploaded logo and favicon PNGs are copied unchanged to `assets/img/`.
- Quote forms are client-side only; submitting opens WhatsApp with a formatted message. The user must press Send in WhatsApp. No lead is stored or emailed.
- Product specifications, availability, delivery times, MOQs and technical integrations must be verified before making firm promises.
- Schema location is area-level, not a fabricated street address. GEO coordinates are supplied by the client and are not asserted as the business's exact location.
- External Google Fonts are used; fallback fonts are provided.
